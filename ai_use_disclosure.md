# AI-use disclosure

Tool: Claude (Anthropic), used through Claude Code with access to this repository and a shell.

## What it did

- Brainstormed topics with me. I rejected two directions (an abstention mechanism with no results,
  and a framework proposal) before settling on the audit.
- Wrote the code in `scripts/` and `src/`, the tests, and first drafts of the manuscript and the
  documentation files.
- Ran the downloads, the extraction of the audited PDFs, and the experiments.

## What I decided

The research question, the choice of an audit over a new model, which
criteria matter for a Ghanaian user, dropping native-speaker review (I do not read Twi well enough),
and what goes in the final paper.

## How the output was verified

- Every quotation from an audited paper is matched by script against text extracted from the PDF
  (`scripts/audit_documentation.py`, `reports/evidence/`). One draft quote turned out to be
  selective: it omitted the authors' next sentence. It was corrected, and the correction is
  recorded in `failure_log.md`.
- Every reference was checked against the ACL Anthology's own BibTeX (saved in
  `reports/references/`) or the arXiv API. One guessed Anthology ID resolved to an unrelated paper
  and was replaced.
- Every number in the paper is written by a script into `reports/metrics/` and traced in the
  README's claims table. `scripts/fill_manuscript.py` writes them into the manuscript.
- A fresh clone of the repository fetched the data and reproduced the metrics files byte for byte.

## What AI was not used for

Labelling data, judging Twi text, or producing any result that is not
regenerated by the committed code.

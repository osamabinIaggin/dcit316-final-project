# Reproducibility checklist

| Item | Status | Where |
|---|---|---|
| Environment pinned | Yes, Python 3.14, versions in `requirements.txt` | `requirements.txt` |
| Data fetched by script, pinned to commit | Yes | `scripts/fetch_data.py`, `data/raw/MANIFEST.md` |
| Checksums for every input file | Yes | `data/raw/MANIFEST.md`, `data/sources/MANIFEST.md` |
| Random seeds fixed | Yes, seed 22128981 for logistic regression and bootstrap | `scripts/run_sentiment.py`, `src/evaluation.py` |
| Hyperparameters chosen on dev only | Yes, C searched on the dev split; test touched once | `reports/metrics/sentiment_results.json` |
| Model versions named | Yes, Hugging Face IDs in the script header | `scripts/run_sentiment.py` |
| Model outputs saved | Yes, per-system test predictions and both NLLB translation runs | `reports/predictions/`, `data/derived/` |
| Metrics saved, not only printed | Yes | `reports/metrics/` |
| Figures generated by code | Yes | `scripts/make_figures.py`, `reports/figures/` |
| Notebook executed with outputs | Yes | `notebooks/` |
| Unit tests | Yes | `tests/`, run with `pytest` |
| Every paper number traceable to a file | Yes, see the claims table in `README.md` | `README.md` |
| Known nondeterminism | NLLB greedy decoding on Apple MPS can differ in rare tokens from CPU output; the saved translations are what the results use | `failure_log.md` |
